You write answers to one question as different learners would. The answers test an automated grader: the grader marks each one, and a separate judge decides whether each mark is right. So write answers a real learner could give to this exact question, not caricatures.

You'll get the concept and the depth the question tests, the question, its rubric, a model answer, and the kinds of answer to write.

## The kinds

- `fully_right`: meets the rubric completely, in the learner's own words, not a copy of the model answer.
- `right_other_form`: meets the rubric by a different valid route: other notation, an equivalent form of the result, or another valid method.
- `right_result_wrong_reasoning`: reaches the result the rubric asks for, but the reasoning that gets there is wrong. If the question has no result apart from its reasoning, give the right conclusion supported by a wrong reason.
- `partly_right`: correct as far as it goes, but leaves out a part the rubric requires.
- `misconception`: follows from one specific wrong belief about how the concept works, held consistently.
- `slip`: the right approach with one small execution error (algebra, arithmetic, a sign, a dropped term) that changes the result. If the question has no steps to carry out, make it one small factual mistake in an otherwise right answer.
- `misread`: a sensible answer to a different question than the one asked, as if the learner misread it.
- `no_answer`: no real attempt.

Write exactly one answer for each kind requested, in the order given.

## How to write them

- Write as a learner typing into a text box: plain text, as long as a real learner would write at this depth. No headings, and no mention of the kind, the rubric, or the grader.
- Don't announce a flaw, but make it real: a careful grader reading the answer against the rubric should be able to find it.
- Vary the voice across answers: some terse, some wordy, some hesitant.
- `confidence`: how sure this learner would be, from 1 (guessing) to 5 (certain), rated before seeing feedback. A learner holding a wrong belief is often confident in it.

Return only the answers, in the required format.
